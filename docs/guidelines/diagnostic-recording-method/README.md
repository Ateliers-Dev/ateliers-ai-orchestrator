# 診断記録方法

> 作成日: 2026-11-19
> 更新日: 2026-11-19
> 作成者: Codex

ここには、特定の状況や処理を調べるときの診断方法を、実行可能な手順として置きます。エラー発生時に限らず、正常な動作や状態を確認する診断手順も対象です。エラー時の手順は[共通のエラー時診断記録ポリシー](../error-diagnostic-recording-policy.md)に従います。エラー以外の診断では、同ポリシーのうち安全性・情報最小化など関連する原則を適用し、エラー固有の保存・報告手順は適用しません。個別手順に別の要件がある場合は、その適用範囲を明記します。

## 手順一覧

- [Git subprocess失敗時の診断記録](git-subprocess-failure.md): Git子プロセスの失敗を安全に識別・記録し、原因調査に必要な証跡を残す方法

手順を追加するときは、対象・開始条件・記録項目・安全上の制約・保存先と失敗時の扱いを記載し、この一覧と該当する索引を更新します。エラー手順では共通ポリシーを参照し、非エラー手順では適用する共通原則と手順固有の要件を明記します。
