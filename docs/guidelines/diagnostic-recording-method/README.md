# 診断記録方法

ここには、特定の状況や処理を調べるときの診断方法を、実行可能な手順として置きます。エラー発生時に限らず、正常な動作や状態を確認する診断手順も対象です。各手順は [共通のエラー時診断記録ポリシー](../error-diagnostic-recording-policy.md) に従います。

## 手順一覧

- [Git subprocess失敗時の診断記録](git-subprocess-failure.md): Git子プロセスの失敗を安全に識別・記録し、原因調査に必要な証跡を残す方法

手順を追加するときは、対象・開始条件・記録項目・安全上の制約・保存先と失敗時の扱いを記載し、この一覧とポリシーの索引を更新します。重複する共通方針は手順へコピーせず、ポリシーを参照してください。
