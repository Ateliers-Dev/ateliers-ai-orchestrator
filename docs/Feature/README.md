# Feature文書について

> 作成日: 2026-11-21
> 更新日: 2026-11-21
> 作成者: yuu503

このフォルダには、Ateliers AI Orchestratorが利用者に提供する機能を説明する文書を置きます。このREADMEはFeature文書の目的と分類を案内する索引です。個別機能の説明は、機能ごとに別のMarkdownファイルとして作成します。

## Featureに含める内容

Feature文書では、利用者が次のことを理解できるように説明します。

- その機能で何ができるか
- どのような場面で役立つか
- 主な動作や利用時の流れ
- 利用上の制約や、人による確認が必要な点

開発者以外にも伝わる平易な日本語を優先し、内部構造や設定スキーマの詳細は必要以上に持ち込まず、必要な場合はReferenceへ案内します。実装済みの機能と、設計・開発中の内容を明確に区別します。

## 他の文書分類との使い分け

- [Reference](../reference/README.md): 設計、仕様、設定項目、内部構造を正確に説明します。
- [Requirements](../requirements/README.md): 機能が満たす要件や受入条件を記録します。
- [Plans](../plans/README.md): 開発の順序やマイルストーンを記録します。

すべての機能についてFeatureとReferenceの両方を作る必要はありません。利用者向けの説明が有用な機能にFeature文書を作成し、技術的な詳細が必要な場合はReferenceへ分けて相互リンクします。
